# Community4You agency dashboard

The agency staff's live view of incidents, reports and SMS conversations, built with Vite + React. It's one of two apps in this repo.

See the [main README](../README.md) for what the project does and how to run it, and [ARCHITECTURE.md](../ARCHITECTURE.md) for the data model and API routes.

```bash
npm install
cp .env.example .env.local   # VITE_SUPABASE_URL, VITE_SUPABASE_PUBLISHABLE_KEY, VITE_API_URL
npm run dev                  # http://localhost:5173
```
